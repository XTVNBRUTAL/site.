LINK TÊN MIỀN CỐ ĐỊNH
Chạy website + Named Tunnel trên VPS luôn bật để bạn và khách truy cập cùng một địa chỉ, kể cả khi tắt máy cá nhân.

          

            
            

              
              
            

            Nhập hostname thuộc tên miền của bạn. Khi bấm Lưu tên miền, website sẽ tự tạo/cập nhật DNS CNAME và Published Route bằng Cloudflare API.
            

              Kết nối Cloudflare một lần — các ID còn lại tự tìm
              
Để tự tìm Zone, lấy Account ID, tạo Named Tunnel, lấy Tunnel Token và cấu hình DNS/route, website chỉ cần một API Token có quyền phù hợp.

              
              

                
                
              

              Chưa lưu API Token. Hãy thêm domain vào Cloudflare và tạo API Token một lần.
              
    
                
  1. Bạn phải sở hữu tên miền, thêm domain vào Cloudflare và hoàn tất đổi nameserver để Zone ở trạng thái Active.
    2. 
                
  2. Trong Cloudflare → My Profile → API Tokens → Create Token → Create Custom Token.
    3. 
                
  3. Cấp đúng quyền: Zone → Zone → Read; Zone → DNS → Read và Zone → DNS → Write (một số màn hình có thể ghi Edit); Account → Cloudflare Tunnel → Read và Account → Cloudflare Tunnel → Write (một số màn hình cũ có thể ghi Edit). Giới hạn token vào Zone/Account của bạn.
    4. 
                
  4. Dán API Token vào ô trên và bấm Lưu token an toàn. Server xác minh và lưu token riêng, không gửi token trở lại trình duyệt. Khi cấu hình lần đầu trên VPS, hãy mở trang Admin qua SSH port-forward.
    5. 
                
  5. Từ lần sau, chỉ cần nhập hostname bạn sở hữu và bấm Lưu tên miền. Website sẽ tự tìm Zone, tạo/tái sử dụng Tunnel, lấy Tunnel Token, cấu hình Published Route và DNS CNAME.
    6. 
              

              Không gửi token qua chat hoặc cho người khác. Nếu token lộ, hãy thu hồi và tạo token mới trong Cloudflare.
